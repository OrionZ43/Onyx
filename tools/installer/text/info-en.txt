Onyx is a one-click secure connection. Click once and Onyx refreshes the server list, tests the servers and connects to the best one.

What Setup will do
• Install Onyx into your user folder — no administrator rights are needed for that.
• Add Onyx to the Start menu and, if you like, to the desktop.
• The sing-box core and the WinTUN driver are already included — nothing is downloaded from the internet.
• If Onyx is already installed, Setup updates it. Your subscriptions, servers and settings are kept.

When Windows asks for permission
Onyx itself runs without administrator rights. Only the VPN network adapter needs them — it is created by a separate tunnel component that Setup installs into "Program Files". So Windows asks for permission once — on the first install (and when the tunnel component is updated), and also if leftovers of an old Onyx version have to be removed. Starting Onyx and connecting need no permission.
