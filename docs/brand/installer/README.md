# Картинки установщика Windows (Inno Setup 6.7, тёмный мастер)

Для установщика «Оникс» (#51), сделано в #52. Знак — лиса V1 «Кабошон» (#42), цвета — токены темы Onyx
(`lib/core/theme/app_theme.dart`). Генератор: `docs/redesign/src/tool/generate_installer_test.dart`
(временно копируется в `test/tool` и запускается как `flutter test`). Превью мастера — `preview.png`.

## Файлы

| Директива | Файлы | Что это |
|---|---|---|
| `WizardImageFile` | `wizard-202x386.png`, `wizard-336x643.png`, `wizard-430x824.png` | «Приветствие» и «Готово», 164:314. Без альфы, края ровно `#0C0C0E` — цвет страниц, шва нет. |
| `WizardSmallImageFile` | `small-58.png`, `small-97.png`, `small-124.png`, `small-159.png` | Шапка внутренних шагов: плоский силуэт лисы шампанью на прозрачном фоне — читается на тёмной шапке при любом размере. |
| (вариант) | `alt/small-volume-*.png` | Объёмная лиса на прозрачном. На тёмной шапке в 58 px мутнее, поэтому не основной. |
| `SetupIconFile`, деинсталлятор | `windows/runner/resources/app_icon.ico` | Иконка приложения (#42). Отдельная иконка для установщика не нужна. |

## Цвета мастера (токены темы Onyx)

| Роль | Цвет |
|---|---|
| Фон страниц | `#0C0C0E` (surface) — в цвет краёв боковой картинки |
| Шапка внутренних шагов | `#131316` (surfaceHigh) |
| Рамка, самый тёмный фон | `#050506` (bg) |
| Разделители, рамки полей | `#222226` (line) |
| Текст | `#F3F1EC` |
| Вторичный текст | `#8F8C86` |

| Акцент: «Далее», прогресс, ссылки | `#D2B98F` (шампань) |
| Текст на акценте | `#050506` |
