# Onyx для Discord из Китая — инструкция · Onyx 中国使用 Discord 指南

_Onyx VPN 0.3.0 (тестовая сборка) · Windows + Android (POCO / HyperOS) · RU ниже, 中文在后半部分_

> Подписи ниже — как в интерфейсе Onyx 0.3.0 (он на русском). Настройки: раздел **«Защита»**. Серверы: **«Подписки и серверы»**.

---

## Русский

### 1. Где взять сервер (выберите одно)

| Вариант | Деньги и регистрация | Стабильность | Голос и видео Discord |
|---|---|---|---|
| **А. Бесплатная подписка** (встроена в Onyx) | ничего | низкая: чужие публичные серверы, живут часы или дни | когда в списке есть сервер с UDP; Onyx сам ищет такие |
| **Б. Свой сервер на AWS** ([aws-setup.md](aws-setup.md)) | регистрация с картой UnionPay; бесплатно до 6 месяцев | высокая: сервер только ваш | да: REALITY + Hysteria2 |

Начните с А, чтобы сразу проверить. Если надоест нестабильность, переходите на Б.

### 2. Установка Onyx на Windows
1. Получите от друга архив `OnyxSetup_….zip` (WeChat, QQ, почта). GitHub из Китая открывается медленно или не открывается.
2. Распакуйте и запустите `onyx_installer.exe` → **Установить**. Ядро sing-box уже внутри, интернет при установке не нужен.
3. Onyx запускается с правами администратора: они нужны для TUN-адаптера (через него идёт голос Discord).
4. Если Windows Defender или SmartScreen ругается: **Подробнее → Выполнить в любом случае**.

### 3. Установка на POCO (Android, HyperOS)
1. Перешлите себе `onyx-0.3.0-android-arm64.apk` и откройте его. Разрешите **«Установка из неизвестных источников»** для того приложения, из которого открыли файл.
2. HyperOS может предупредить «непроверенное приложение» → **Всё равно установить**.
3. Чтобы HyperOS не убивал VPN в фоне:
   - Настройки → Приложения → **Onyx** → **Контроль активности / Battery saver** → **Нет ограничений**;
   - там же **Автозапуск** → включить;
   - в списке недавних приложений потяните карточку Onyx вниз и нажмите **замок**.
4. При первом подключении Android спросит разрешение на VPN → **ОК**.

### 4. Добавить серверы
- **Вариант А (бесплатно):**
  - Onyx → **«Подписки и серверы»** → **«Бесплатные серверы для Китая»**. Подписка добавляется к остальным, ничего не заменяет.
  - До выхода новой UI-ветки можно вставить ссылку вручную: `https://raw.githubusercontent.com/Pawdroid/Free-servers/main/sub`. Если GitHub недоступен, Onyx сам попробует зеркала.
- **Вариант Б (свой сервер):** Onyx → **«Подписки и серверы»** → **«Добавить серверы или источник»** → вставьте целиком строку, которую выдал скрипт на сервере.

После загрузки Onyx проверит все серверы:
1. доступность;
2. реальный HTTPS;
3. **UDP**: можно ли через сервер говорить в Discord.

Серверы с рабочим UDP поднимутся выше в списке.

### 5. Настройки Onyx
1. **«Умная маршрутизация»** → включена, **«Регион маршрутизации» → «Китай»**. Китайские сайты (WeChat, Bilibili, Taobao, банки) пойдут напрямую, без VPN; всё остальное — через VPN.
2. **«Режим Discord»** → включён:
   - Discord гарантированно идёт через VPN (на Windows — весь трафик программы Discord, включая голос);
   - при выборе сервера предпочитаются серверы с UDP.
3. **«Автопереключение серверов»** → включено: если сервер умер, Onyx перейдёт на другой. Можно создать группу (например «Для Discord») и выбрать «Автовыбор из этой группы» — тогда Onyx выбирает только из неё.

### 6. Проверка
1. Подключитесь (большая кнопка).
2. Нажмите **«Проверить UDP (голос)»** в разделе «Защита»:
   - «UDP работает: 5/5, … мс — голос Discord пойдёт» — всё хорошо;
   - «UDP не проходит» — выберите другой сервер (для своего сервера — сначала Hysteria2, потом REALITY).
3. Откройте Discord.

### 7. Настройки Discord
1. **Регион голосового канала — по стране выхода VPN, а не по Китаю.** Голос идёт так: вы → сервер VPN → голосовой сервер Discord. Серверы VPN у вас в Европе (Финляндия, Франция), поэтому голосовой регион нужен европейский:
   - на своём Discord-сервере: шестерёнка канала → **Обзор → Region Override → «Automatic»** (Discord сам выберет регион рядом с сервером VPN) или **Rotterdam**;
   - **не ставьте Hong Kong или Japan**: тогда голос пойдёт Китай → Европа → Азия и обратно, и задержка вырастет почти вдвое;
   - пинг смотрите в «Voice Connected → Connection info»;
   - в личных звонках регион выбирается автоматически.
2. **Растёт пинг в голосе или рвётся связь — переключитесь на HY2.** На REALITY голос Discord (UDP) идёт внутри TCP-соединения, и при потерях на дороге из Китая задерживается весь поток. HY2 передаёт голос по UDP напрямую. На главном экране «Сменить» → **«Finland HY2»** или **«France HY2»**: выбранный вручную сервер Onyx сам не меняет. Если на HY2 хуже — вернитесь на REALITY или «Автовыбор».
3. **Go Live (стрим):** начинайте с **720p 30fps**; если не тормозит, поднимайте.
4. **Настройки → Голос и видео:**
   - «Включить QoS высокого приоритета» → **выключить** (через VPN это не помогает, а на некоторых сетях мешает);
   - «Аппаратное ускорение H.264» → включено.
5. Если Discord застрял на **«RTC Connecting»**, UDP не проходит. Сделайте «Проверить UDP» и смените сервер.

### 8. Честно о рисках
- Бесплатные серверы чужие. Владелец видит, на какие сайты вы ходите, но не содержимое: Discord шифрует трафик. Включите в Discord **двухфакторную аутентификацию**. Не входите через такие серверы в банк.
- В чувствительные даты (4 июня, октябрь, съезды) блокировки усиливаются. Держите несколько серверов или свой.

## 中文（简体）

> 下面的按钮名称与 Onyx 0.3.0 界面一致（界面为俄语）。设置在 **«Защита»（防护）** 分区，服务器在 **«Подписки и серверы»（订阅与服务器）**。

### 1. 服务器从哪里来（二选一）

| 方案 | 费用与注册 | 稳定性 | Discord 语音/视频 |
|---|---|---|---|
| **A. 免费订阅**（Onyx 内置） | 不需要 | 低：公共节点，可能几小时或几天就失效 | 列表里有支持 UDP 的节点时可以；Onyx 会自动筛选 |
| **B. 自己的 AWS 服务器**（见 [aws-setup.md](aws-setup.md)） | 需要用银联卡注册；最多免费 6 个月 | 高：只有你自己用 | 可以：REALITY + Hysteria2 |

建议先用 A 试一下，嫌不稳定再换 B。

### 2. Windows 安装
1. 通过微信、QQ 或邮箱接收 `OnyxSetup_….zip`（在国内访问 GitHub 很慢或打不开）。
2. 解压后运行 `onyx_installer.exe` → **安装**。sing-box 内核已经包含在安装包里，安装时不需要联网。
3. Onyx 需要管理员权限运行：TUN 虚拟网卡需要管理员权限，Discord 语音就是通过它传输的。
4. 如果 Windows Defender / SmartScreen 拦截：**更多信息 → 仍要运行**。

### 3. POCO 手机（Android / HyperOS）安装
1. 把 `onyx-0.3.0-android-arm64.apk` 发到手机上并打开。为打开文件的应用开启**「安装未知应用」**权限。
2. HyperOS 提示「未经验证的应用」时 → **仍然安装**。
3. 防止 HyperOS 在后台杀掉 VPN：
   - 设置 → 应用 → **Onyx** → **省电策略** → **无限制**；
   - 同一页面开启**自启动**；
   - 在最近任务里把 Onyx 卡片下拉**锁定**。
4. 第一次连接时 Android 会请求 VPN 权限 → **确定**。

### 4. 添加服务器
- **方案 A（免费）**：
  - Onyx → **«Подписки и серверы»** → **«Бесплатные серверы для Китая」（中国免费服务器）**。会添加到现有订阅中，不会替换。
  - 新界面上线之前，也可以手动粘贴：`https://raw.githubusercontent.com/Pawdroid/Free-servers/main/sub`。打不开 GitHub 时 Onyx 会自动尝试镜像。
- **方案 B（自建）**：Onyx → **«Подписки и серверы»** → **«Добавить серверы или источник»（添加服务器或来源）** → 粘贴服务器脚本输出的整行字符串。

加载后 Onyx 会依次检测每个节点：
1. 能否连上；
2. 能否真正打开 HTTPS；
3. **UDP 能否通过**（Discord 语音需要 UDP）。

UDP 正常的节点会排在前面。

### 5. Onyx 设置
1. **智能分流（«Умная маршрутизация»）** → 开启，**«Регион маршрутизации»（分流地区）→ «Китай»（中国）**。国内网站（微信、B 站、淘宝、银行）直连不走 VPN，其余走 VPN。
2. **Discord 模式（«Режим Discord»）** → 开启：
   - Discord 一定走 VPN（Windows 上整个 Discord 程序包括语音都走 VPN）；
   - 选服务器时优先选支持 UDP 的节点。
3. **自动切换（«Автопереключение серверов»）** → 开启：节点失效时自动换到别的节点。也可以建一个分组（例如「Для Discord」），选择「Автовыбор из этой группы」（仅从此分组自动选择）。

### 6. 检测
1. 点大按钮连接。
2. 在「Защита」分区点 **「Проверить UDP (голос)」（检测 UDP）**：
   - 显示「UDP работает: 5/5 …」= 正常，Discord 语音可以用；
   - 显示「UDP не проходит」= 请换节点（自建服务器先试 Hysteria2，再试 REALITY）。
3. 打开 Discord。

### 7. Discord 设置
1. **语音频道地区按 VPN 出口所在国家选，而不是按中国选。** 语音的路径是：你 → VPN 服务器 → Discord 语音服务器。你的 VPN 服务器在欧洲（芬兰、法国），所以语音地区要选欧洲：
   - 在自己的 Discord 服务器里：频道齿轮 → **概览 → 地区覆盖（Region Override）→「Automatic」（自动）**（Discord 会自动选离 VPN 服务器近的地区）或 **Rotterdam**；
   - **不要选 Hong Kong 或 Japan**：那样语音会走 中国 → 欧洲 → 亚洲 再回来，延迟几乎翻倍；
   - 在「语音已连接 → 连接信息」里看延迟；
   - 私聊通话会自动选择地区。
2. **语音延迟变高或断线时，换成 HY2。** 用 REALITY 时，Discord 语音（UDP）包在 TCP 连接里传输，从中国出去的线路一丢包，整个连接都会被拖慢；HY2 直接用 UDP 传语音。主界面 «Сменить»（更换）→ 选 **«Finland HY2»** 或 **«France HY2»**（手动选择的服务器 Onyx 不会自动更换）。如果 HY2 更差，就换回 REALITY 或 «Автовыбор»（自动选择）。
3. **Go Live 直播**：先用 **720p 30fps**，不卡再调高。
4. **设置 → 语音和视频**：
   - 「启用服务质量高包优先级」→ **关闭**；
   - 「H.264 硬件加速」→ 开启。
5. 如果一直显示 **「RTC 正在连接」**，说明 UDP 不通：点「检测 UDP」，换节点。

### 8. 风险提示
- 免费节点是别人的服务器。对方能看到你访问了哪些网站，但看不到内容（Discord 是加密的）。请给 Discord 开启**两步验证**，不要通过这些节点登录银行。
- 敏感日期（6 月 4 日、十月、重大会议期间）封锁会加强，建议多备几个节点或使用自己的服务器。
