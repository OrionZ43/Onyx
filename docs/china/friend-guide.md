# Onyx для Discord из Китая — инструкция · Onyx 中国使用 Discord 指南

_Onyx VPN 0.3.0 (тестовая сборка) · Windows + Android (POCO / HyperOS) · RU ниже, 中文在后半部分_

> Подписи ниже — как в интерфейсе Onyx 0.3.0 (он на русском). Главное — одна кнопка подключения; настройки — в **«Настройках»**, серверы — в **«Подписки и серверы»**.

## Русский

### 1. Где взять сервер (выберите одно)

| Вариант | Деньги и регистрация | Стабильность | Голос и видео Discord |
|---|---|---|---|
| **А. Бесплатная подписка** (встроена в Onyx) | ничего | низкая: чужие публичные серверы, живут часы или дни | когда в списке есть сервер с UDP; Onyx сам ищет такие |
| **Б. Свой сервер на AWS** ([aws-setup.md](aws-setup.md)) | регистрация с картой UnionPay; бесплатно до 6 месяцев | высокая: сервер только ваш | да: REALITY + Hysteria2 |

Начните с А, чтобы сразу проверить. Если надоест нестабильность, переходите на Б.

### 2. Установка Onyx на Windows
1. Получите от друга файл `OnyxSetup_….exe` (WeChat, QQ, почта) — один файл, около 33 МБ. GitHub из Китая открывается медленно или не открывается.
2. Запустите его. Если SmartScreen пишет «Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае** (у сборки пока нет цифровой подписи).
3. Язык установщик берёт из Windows (на китайской Windows — 中文). Дальше: **Далее** → **Далее** (папка по умолчанию подходит) → галочки: «Ярлык на рабочем столе»; «Запускать Onyx при входе в систему» — по желанию → **Установить**. Windows один раз спросит разрешение — поставить компонент VPN-туннеля → **Да** → **Завершить**. Ядро sing-box уже внутри, интернет при установке не нужен.
4. Если Onyx уже стоял (в том числе старая версия из zip): просто установите новую поверх — та же папка, подписки и настройки сохранятся. Остатки старой версии установщик уберёт в том же запросе разрешения.
5. Сам Onyx запускается и подключается без прав администратора — разрешение при каждом запуске больше не нужно. Когда выйдет новая версия, Onyx предложит её сам и поставит тем же установщиком; Windows спросит разрешение, только если обновился компонент туннеля. Автозапуск можно поменять в Onyx: **Настройки → «Запуск»**.
6. Удалить: «Параметры → Приложения» → **Onyx VPN** → **Удалить**. Установщик спросит, удалить ли подписки и настройки; по умолчанию они остаются.

### 3. Установка на POCO (Android, HyperOS)
1. Перешлите себе `onyx-…-android-arm64.apk` и откройте его. Разрешите **«Установка из неизвестных источников»** для того приложения, из которого открыли файл. Если Onyx уже стоял — устанавливайте поверх, данные сохранятся.
2. HyperOS может предупредить «непроверенное приложение» → **Всё равно установить**.
3. Чтобы HyperOS не убивал VPN в фоне:
   - Настройки → Приложения → **Onyx** → **Контроль активности / Battery saver** → **Нет ограничений**;
   - там же **Автозапуск** → включить;
   - в списке недавних приложений потяните карточку Onyx вниз и нажмите **замок**.
4. При первом подключении Android спросит разрешение на VPN → **ОК**.

### 4. Добавить серверы
- **Вариант А (бесплатно):**
  - Onyx → **«Подписки и серверы»** → **«Бесплатные серверы для Китая»**. Подписка добавляется к остальным, ничего не заменяет.
  - До выхода новой UI-ветки можно вставить ссылку вручную: `https://raw.githubusercontent.com/Pawdroid/Free-servers/main/sub`. Если GitHub недоступен, Onyx сам попробует зеркала.
- **Вариант Б (свой сервер):** Onyx → **«Подписки и серверы»** → **«Добавить серверы или источник»** → вставьте целиком строку, которую выдал скрипт на сервере.

После загрузки Onyx проверит все серверы:
1. доступность;
2. реальный HTTPS;
3. **UDP**: можно ли через сервер говорить в Discord.

Серверы с рабочим UDP поднимутся выше в списке.

### 5. Подключение — одна кнопка
Ничего настраивать не нужно. Нажмите большую кнопку подключения — Onyx сам:
1. обновит подписку (если давно не обновлялась), при недоступности GitHub — через зеркала;
2. проверит серверы: доступность, реальный HTTPS и **UDP** (голос Discord). Под кнопкой видно: «Обновляю подписку…», «Проверяю серверы… 3/20», «Подключаюсь к …»;
3. выберет лучший живой сервер — для Discord с рабочим UDP — и подключится;
4. если сервер в процессе начнёт подвисать, Onyx перепроверит запасные и перейдёт только на заметно более быстрый (уведомление «Переключились: A → B»). Если такого нет — останется на текущем и честно скажет «Стабильного сервера сейчас нет». Сервер, выбранный вручную, Onyx сам не меняет. Выключить автопереключение: **Настройки → «Защита» → «Автоматически менять сервер при ухудшении»**.

Если не получилось — под кнопкой будет причина и кнопка **«Обновить и повторить»** (или «Добавить сервер»). Пока идёт подбор, его можно отменить той же кнопкой («Отмена»).

Настройки по умолчанию уже правильные: **«Регион маршрутизации» → «Авто»** (Onyx сам определяет страну по IP и часовому поясу) — в Китае сам включит «Китай» (китайские сайты напрямую, остальное через VPN); **«Режим Discord»** включён. Менять их можно в **Настройках**, если нужно. Продвинутым: можно выбрать сервер или группу вручную в «Подписки и серверы» — тогда Onyx подключается именно к нему.

На Windows: клик по лисе в трее (у часов) открывает мини-панель с кнопкой подключения, двойной клик — главное окно.

### 6. Проверка
1. Подключитесь (большая кнопка) и дождитесь «Защита активна».
2. По желанию: **«Проверить UDP (голос)»** в Настройках → «Защита»:
   - «UDP работает: 5/5, … мс — голос Discord пойдёт» — всё хорошо;
   - «UDP заблокирован на этом сервере» — выберите другой сервер;
   - «Сервер недоступен» — сервер не отвечает вообще; нажмите кнопку подключения ещё раз — Onyx подберёт другой.
3. Откройте Discord и **сразу зайдите в голосовой канал** (раньше вход падал — это исправлено), посмотрите чужой стрим.
### 7. Настройки Discord
1. **Регион голосового канала — по стране выхода VPN, а не по Китаю.** Голос идёт так: вы → сервер VPN → голосовой сервер Discord. Серверы VPN у вас в Европе (Финляндия, Франция), поэтому голосовой регион нужен европейский:
   - на своём Discord-сервере: шестерёнка канала → **Обзор → Region Override → «Automatic»** (Discord сам выберет регион рядом с сервером VPN) или **Rotterdam**;
   - **не ставьте Hong Kong или Japan**: тогда голос пойдёт Китай → Европа → Азия и обратно, и задержка вырастет почти вдвое;
   - пинг смотрите в «Voice Connected → Connection info»;
   - в личных звонках регион выбирается автоматически.
2. **Растёт пинг в голосе или рвётся связь — переключитесь на HY2.** На REALITY голос Discord (UDP) идёт внутри TCP-соединения, и при потерях на дороге из Китая задерживается весь поток. HY2 передаёт голос по UDP напрямую. Нажмите карточку сервера внизу главного экрана (в окне Windows — «Сменить» справа) → **«Finland HY2»** или **«France HY2»**: выбранный вручную сервер Onyx сам не меняет. Если на HY2 хуже — вернитесь на REALITY или «Автовыбор».
3. **Go Live (стрим):** начинайте с **720p 30fps**; если не тормозит, поднимайте.
4. **Настройки → Голос и видео:**
   - «Включить QoS высокого приоритета» → **выключить** (через VPN это не помогает, а на некоторых сетях мешает);
   - «Аппаратное ускорение H.264» → включено.
5. Если Discord застрял на **«RTC Connecting»**, UDP не проходит. Сделайте «Проверить UDP» и смените сервер.

### 8. Честно о рисках
- Бесплатные серверы чужие. Владелец видит, на какие сайты вы ходите, но не содержимое: Discord шифрует трафик. Включите в Discord **двухфакторную аутентификацию**. Не входите через такие серверы в банк.
- В чувствительные даты (4 июня, октябрь, съезды) блокировки усиливаются. Держите несколько серверов или свой.

## 中文（简体）

> 下面的按钮名称与 Onyx 0.3.0 界面一致（界面为俄语）。最重要的是一个连接按钮；设置在 **«Настройки»（设置）**，服务器在 **«Подписки и серверы»（订阅与服务器）**。

### 1. 服务器从哪里来（二选一）

| 方案 | 费用与注册 | 稳定性 | Discord 语音/视频 |
|---|---|---|---|
| **A. 免费订阅**（Onyx 内置） | 不需要 | 低：公共节点，可能几小时或几天就失效 | 列表里有支持 UDP 的节点时可以；Onyx 会自动筛选 |
| **B. 自己的 AWS 服务器**（见 [aws-setup.md](aws-setup.md)） | 需要用银联卡注册；最多免费 6 个月 | 高：只有你自己用 | 可以：REALITY + Hysteria2 |

建议先用 A 试一下，嫌不稳定再换 B。

### 2. Windows 安装
1. 通过微信、QQ 或邮箱接收 `OnyxSetup_….exe`（一个文件，约 33 MB；在国内访问 GitHub 很慢或打不开）。
2. 运行它。如果 SmartScreen 提示「Windows 已保护你的电脑」：**更多信息 → 仍要运行**（安装包暂时没有数字签名）。
3. 安装程序会按 Windows 的语言自动显示中文。依次点 **下一步** → **下一步**（默认文件夹即可）→ 勾选「在桌面创建快捷方式」；「登录 Windows 时自动启动 Onyx」可选 → **安装**。Windows 会请求一次权限，用于安装 VPN 隧道组件 → 点 **是** → **完成**。sing-box 内核已经包含在内，安装时不需要联网。
4. 如果之前装过 Onyx（包括旧的 zip 版）：直接安装新版覆盖即可——同一个文件夹，订阅和设置都会保留。旧版本的残留会在同一次权限请求中一并清理。
5. Onyx 本身启动和连接都不需要管理员权限——不会再每次启动都询问。有新版本时 Onyx 会自己提示，并用同一个安装程序完成更新；只有隧道组件更新时 Windows 才会再请求权限。开机自启可以在 Onyx 中修改：**设置 → «Запуск»（启动）**。
6. 卸载：「设置 → 应用」→ **Onyx VPN** → **卸载**。卸载程序会询问是否同时删除订阅和设置，默认保留。

### 3. POCO 手机（Android / HyperOS）安装
1. 把 `onyx-…-android-arm64.apk` 发到手机上并打开。为打开文件的应用开启**「安装未知应用」**权限。之前装过 Onyx 的话直接覆盖安装，数据会保留。
2. HyperOS 提示「未经验证的应用」时 → **仍然安装**。
3. 防止 HyperOS 在后台杀掉 VPN：
   - 设置 → 应用 → **Onyx** → **省电策略** → **无限制**；
   - 同一页面开启**自启动**；
   - 在最近任务里把 Onyx 卡片下拉**锁定**。
4. 第一次连接时 Android 会请求 VPN 权限 → **确定**。

### 4. 添加服务器
- **方案 A（免费）**：
  - Onyx → **«Подписки и серверы»** → **«Бесплатные серверы для Китая」（中国免费服务器）**。会添加到现有订阅中，不会替换。
  - 新界面上线之前，也可以手动粘贴：`https://raw.githubusercontent.com/Pawdroid/Free-servers/main/sub`。打不开 GitHub 时 Onyx 会自动尝试镜像。
- **方案 B（自建）**：Onyx → **«Подписки и серверы»** → **«Добавить серверы или источник»（添加服务器或来源）** → 粘贴服务器脚本输出的整行字符串。

加载后 Onyx 会依次检测每个节点：
1. 能否连上；
2. 能否真正打开 HTTPS；
3. **UDP 能否通过**（Discord 语音需要 UDP）。

UDP 正常的节点会排在前面。

### 5. 连接——只需一个按钮
不需要任何设置。点大的连接按钮，Onyx 会自动：
1. 更新订阅（太久没更新时），GitHub 打不开时自动用镜像；
2. 检测服务器：能否连通、真实 HTTPS、**UDP**（Discord 语音）。按钮下方会显示：「Обновляю подписку…」（正在更新订阅）、「Проверяю серверы… 3/20」（正在检测服务器）、「Подключаюсь к …」（正在连接）；
3. 选出最好的可用服务器——Discord 优先选 UDP 可用的——并连接；
4. 使用中服务器变慢或卡顿时，Onyx 会先检测备用服务器，只有找到明显更快的才会切换（提示「Переключились: A → B」）；找不到就留在当前服务器，并提示「Стабильного сервера сейчас нет」（暂时没有稳定的服务器）。手动选择的服务器不会被自动更换。关闭自动切换：**设置 → «Защита» → «Автоматически менять сервер при ухудшении»**（服务器变差时自动更换）。

如果失败，按钮下方会显示原因和 **「Обновить и повторить」（更新并重试）** 按钮（或「添加服务器」）。自动选择过程中可以再点一次按钮取消（「Отмена」）。

默认设置已经正确：**「Регион маршрутизации」→「Авто」**（自动：Onyx 会根据 IP 和时区自动判断所在国家）——在中国会自动切到「中国」（国内网站直连，其余走 VPN）；**「Режим Discord」** 已开启。需要时可在 **设置** 中修改。高级用户也可以在「Подписки и серверы」里手动选服务器或分组。

Windows：单击托盘（时钟旁）的狐狸图标打开迷你面板（有连接按钮），双击打开主窗口。

### 6. 检测
1. 点大按钮连接，等出现「Защита активна」（保护已开启）。
2. 可选：在设置 →「Защита」点 **「Проверить UDP (голос)」（检测 UDP）**：
   - 「UDP работает: 5/5 …」= 正常，Discord 语音可以用；
   - 「UDP заблокирован на этом сервере」= 此服务器 UDP 被封，请换服务器；
   - 「Сервер недоступен」= 服务器完全没响应，再点一次连接按钮，Onyx 会自动换一个。
3. 打开 Discord，**直接进入语音频道**（以前进不去的问题已修复），试着观看别人的直播。
### 7. Discord 设置
1. **语音频道地区按 VPN 出口所在国家选，而不是按中国选。** 语音的路径是：你 → VPN 服务器 → Discord 语音服务器。你的 VPN 服务器在欧洲（芬兰、法国），所以语音地区要选欧洲：
   - 在自己的 Discord 服务器里：频道齿轮 → **概览 → 地区覆盖（Region Override）→「Automatic」（自动）**（Discord 会自动选离 VPN 服务器近的地区）或 **Rotterdam**；
   - **不要选 Hong Kong 或 Japan**：那样语音会走 中国 → 欧洲 → 亚洲 再回来，延迟几乎翻倍；
   - 在「语音已连接 → 连接信息」里看延迟；
   - 私聊通话会自动选择地区。
2. **语音延迟变高或断线时，换成 HY2。** 用 REALITY 时，Discord 语音（UDP）包在 TCP 连接里传输，从中国出去的线路一丢包，整个连接都会被拖慢；HY2 直接用 UDP 传语音。点主界面底部的服务器卡片（Windows 窗口里是右侧的 «Сменить»）→ 选 **«Finland HY2»** 或 **«France HY2»**（手动选择的服务器 Onyx 不会自动更换）。如果 HY2 更差，就换回 REALITY 或 «Автовыбор»（自动选择）。
3. **Go Live 直播**：先用 **720p 30fps**，不卡再调高。
4. **设置 → 语音和视频**：
   - 「启用服务质量高包优先级」→ **关闭**；
   - 「H.264 硬件加速」→ 开启。
5. 如果一直显示 **「RTC 正在连接」**，说明 UDP 不通：点「检测 UDP」，换节点。

### 8. 风险提示
- 免费节点是别人的服务器。对方能看到你访问了哪些网站，但看不到内容（Discord 是加密的）。请给 Discord 开启**两步验证**，不要通过这些节点登录银行。
- 敏感日期（6 月 4 日、十月、重大会议期间）封锁会加强，建议多备几个节点或使用自己的服务器。
